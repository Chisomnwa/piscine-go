# piscine-go

## Overview

This repository contains all exercises, tasks, and mini-projects completed during the **one-month coding piscine** focused on learning programming fundamentals with Go.

The goal of the piscine was to immerse learners in problem-solving, Go syntax, and basic software engineering principles through hands-on exercises.

## Languages & Tools

***Language:*** Go

***Version:*** Go 1.25.2

***Tools:*** VS Code / Go CLI / Git

### Goals & Learning Outcomes

During this piscine, I focused on:

- Go basics: variables, loops, conditionals, functions

- Data structures: arrays, slices, maps, structs

- Pointers and memory management

- File I/O and simple error handling

- Debugging and testing small programs

- Version control using Git

### Highlights

- Completed daily coding exercises to strengthen problem-solving skills.

- Built mini-projects demonstrating understanding of Go fundamentals.

- Developed a portfolio of Go programs for reference and growth.

### Notes

The repository is intended as a learning record; solutions are my own work.

The tasks are structured to gradually increase in difficulty, reflecting the immersive style of the piscine.
